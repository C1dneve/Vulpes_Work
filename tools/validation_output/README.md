# Saídas de validação

Esta pasta é destinada a resultados gerados localmente pelas ferramentas de diagnóstico. Saídas reais podem conter nomes, chaves de issues, metadados operacionais ou outros dados do ambiente e **nunca devem ser commitadas nem compartilhadas**.

`results.example.json` contém somente a estrutura de campos com valores fictícios. Os arquivos `results.json` e `console.log` reais são ignorados pelo Git e devem permanecer locais.
